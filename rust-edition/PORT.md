# Самостоятельный порт Torrent 1.4.0

Цель экспериментальной ветки — приложение Windows 11 x64 на Rust. Эталон поведения — `v1.4.0`. Граница с libtorrent-rasterbar допускает новый узкий адаптер C ABI для его C++ API. Код клиента из `src/*.cpp` и его заголовков используется как эталон для сверки и исключается из сборки нового приложения. Текущий Rust-код собирается отдельно через Cargo. Старый Preview 1 остаётся историческим гибридным экспериментом.

| Этап | Сделано | Критерий завершения |
|---|---|---|
| Профиль | Чтение и запись настроек, формат позиции окна и восстановление координат, чтение порядка очереди и непрозрачных resume-данных | Проверить запись, повторное чтение и атомарную замену файлов на Windows |
| Движок и очередь | Новый адаптер подключён к Rust. Сессия принимает 16 активных загрузок, 1 раздачу, 17 суммарно для auto-managed торрентов, 80 соединений как в 1.4.0. На libtorrent 2.0.11 проверены открытие сессии, добавление magnet и .torrent, пауза, возобновление, удаление и приоритеты файлов | Подключить сохранение и восстановление сессии, получение статуса и метаданных для интерфейса. Проверить скачивание нескольких торрентов одновременно, сохранение выбора файлов и восстановление после перезапуска на Windows. |
| Нативный интерфейс | Предстоит | Главное окно, темы, настройки, диалоги, сортировка, клавиатурная навигация, перетаскивание и запуск из оболочки. Сверить русскую и английскую версии, снимки и сценарии взаимодействия с 1.4.0 |
| Дистрибутив | Публикация из ветки отключена | Полный сценарий Windows на чистом и уже существующем профиле, измерения ресурсов и отдельная проверка установки, обновления и удаления |

Лимит относится к auto-managed торрентам libtorrent. Отдельно нужно проверить ожидаемое поведение ручного запуска и получения метаданных перед выбором файлов. [Документация параметров libtorrent](https://www.libtorrent.org/reference-Settings.html)
