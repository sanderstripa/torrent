# Montserrat

Unmodified Regular font from the [official Montserrat project](https://github.com/JulietaUla/Montserrat). The pinned upstream revision is in `upstream.txt`; source file metadata is in `regular-upstream.json`. Distributed under the SIL Open Font License in `OFL.txt`.

The same font is embedded in both executable resources and loaded privately with DirectWrite and GDI. It supports Cyrillic and Latin text. It is not installed as a Windows system font. The installer includes the license in the installed dependency licenses.
