# Montserrat

Unmodified variable font from the [official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/montserrat). The pinned upstream revision is in `upstream.txt`. Distributed under the SIL Open Font License in `OFL.txt`.

The font is embedded in both executable resources and loaded privately with DirectWrite. It supports the client's Cyrillic and Latin interface text. It is not installed as a Windows system font. The installer includes the license in the installed dependency licenses.
